    Tạo notebook

    Mở NotebookLM ↗

    Bấm Create notebook, rồi đổi tên notebook thành .

    2

    Thêm đúng 2 nguồn

    Cách nhanh – kéo thả: AI đã mở sẵn thư mục chứa file khi làm xong. Kéo 2 file sau vào khung Add sources:

      Đã lỡ đóng thư mục? Bấm Copy đường dẫn, trong NotebookLM chọn Add sources → Upload, dán vào ô địa chỉ của hộp chọn file, Enter, rồi chọn 2 file trên.

      Xem thư mục ↗
      Cách dự phòng – dán chữ (không cần file): Chọn Add sources → Copied text, dán từng phần, mỗi phần là một nguồn:

      Notebook chỉ được có đúng 2 nguồn này, cả 2 đều được tích chọn.

      Dán vào ô Custom topic (mục "What should the video focus on?") → bấm Generate. Có thể đóng tab, NotebookLM vẫn tiếp tục tạo.
