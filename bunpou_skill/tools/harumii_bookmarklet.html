Cách dùng: mở trang xem ngữ pháp …/admin/grammar-pool/n3/<id>?mode=view, đợi bài giảng hiện đủ → bấm bookmark → file <tên mẫu>.md được tải về.

Kiểm chứng: script so chữ/số của markdown với bài giảng đang hiển thị. Khớp → hiện thông báo xanh "✓ Khớp 100%". Lệch → hiện cảnh báo chỉ rõ vị trí lệch và hỏi có vẫn tải không.
