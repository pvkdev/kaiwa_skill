## A NOTE TO STUDENTS

In class, conversation practice is the most important part of language study, but classroom practice alone is inadequate for the student who wishes to become proficient in a limited amount of time. The volume of exercises is intended to compensate for that insufficiency.

In this book there are two kinds of exercises. One is sentence pattern exercises, the other is conversation exercises. These exercises are basically for home study. Those expressions and sentence patterns which are already familiar should be practiced before class, and new expressions and patterns should be practiced after they have been introduced in class. Try to do the oral drills completely, using normal conversational speed and correct pronunciation, while looking at the text as little as possible.

<a id="p0005-b002"></a>
## How To Use The Book

- **Sentence Pattern Exercises**

  An example is given before each exercise. By following the example it should become clear how each exercise is to be done. The exercises include Substitution Drills, Expansion Drills, Question and Answer Drills, Repetition Drills, and others.

- **Conversation Exercises**

  Successfully practicing conversation exercises alone is always a difficult task. To facilitate this task, practice tapes have been provided which contain conversation exercises. Before each exercise, an example is given in which the setting for each conversation is explained. The section printed in bold-faced (Gothic) type (on the left) is the practice section for the student. First, the student should practice the oral drills which require her/him to concentrate on pronunciation and sentence structure. Afterwards the student will either initiate or respond to the tape according to the Discourse Pattern. The student should practice the exercise until he/she can perform it smoothly without referring to the text.

JLPT Mogi Yuuki Bui
