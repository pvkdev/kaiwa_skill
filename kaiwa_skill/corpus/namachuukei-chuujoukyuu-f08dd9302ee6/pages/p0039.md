# 4「渋滞してるらしいですよ」

Furigana (nguồn): 渋滞＝じゅうたい

―確かな情報・不確かな情報―

Furigana (nguồn): 確＝たし、情報＝じょうほう、不確＝ふたし

何かの理由で、友人との待ち合わせの時間に遅れそうです。あなたならなんと言いますか。

Furigana (nguồn): 理由＝りゆう、遅＝おく

<a id="p0039-b002"></a>
## こんなとき、どう言いますか

次の情報は、a. 誰かから聞いた、b. 話し手が考えた、のどちらですか。

Furigana (nguồn): 情報＝じょうほう、誰＝だれ

<a id="p0039-b003"></a>
①

- ア）（　）今度、学校の前にできたレストラン、おいしいそうね。

Furigana (nguồn): 今度＝こんど

- イ）（　）今度、学校の前にできたレストラン、よさそうね。
- ウ）（　）今度、学校の前にできたレストラン、おいしいんだって。

<a id="p0039-b004"></a>
②

- ア）（　）毎日、満員電車で通勤するのって疲れるよ。

Furigana (nguồn): 満員＝まんいん、通勤＝つうきん、疲＝つか

- イ）（　）毎日、満員電車で通勤するのって疲れそうだね。
- ウ）（　）毎日、満員電車で通勤するのって疲れるんだってね。

<a id="p0039-b005"></a>
③

- ア）（　）朝夕の子どもの送り迎えは大変ですね。

Furigana (nguồn): 朝夕＝あさゆう、送＝おく、迎＝むか

- イ）（　）朝夕の子どもの送り迎えは大変なんですよ。
- ウ）（　）朝夕の子どもの送り迎えは大変だそうですよ。

<a id="p0039-b006"></a>
④

- ア）（　）あそこのスーパー、来週開店するみたいね。

Furigana (nguồn): 開店＝かいてん

- イ）（　）あそこのスーパー、来週開店するみたいよ。
- ウ）（　）あそこのスーパー、来週開店するんじゃない？

<a id="p0039-b007"></a>
⑤

- ア）（　）ディズニーランドは、大人も楽しめるみたいよ。
- イ）（　）ディズニーランドは、大人も楽しめるらしいよ。
- ウ）（　）ディズニーランドは、大人も楽しめると思うけど。
