## Unit 5 — section 2

CD 38

1.

   **A:** 先生、ご無沙汰してます。

   Furigana (nguồn): 先生＝せんせい、無＝ぶ、沙＝さ、汰＝た

   **B:** あ、山田君。最近どうですか？

   Furigana (nguồn): 山田＝やまだ、君＝くん、最近＝さいきん

   **A:** ええ、なんとかやってます。

2. D

   **A:** 田中さん、カゼをこじらせて入院したそうですよ。

   Furigana (nguồn): 田中＝たなか、入院＝にゅういん

   **B:** えっ、じゃ、お見舞いにいかなくちゃ。

   Furigana (nguồn): 見＝み、舞＝ま

   **A:** 行くなら一緒に行きませんか？

   Furigana (nguồn): 行＝い、一緒＝いっしょ

3. C

   **A:** どう？　今日、焼き肉に行かない？

   Furigana (nguồn): 今日＝きょう、焼＝や、肉＝にく

   **B:** 焼き肉か～、おととい、食べ放題で、いやっていうほど肉を食べたんですよ。

   Furigana (nguồn): 食＝た、放題＝ほうだい

   **A:** へー、いいなー。じゃ、今日もそこ行かない？

   **B:** だから！

4. C

   **A:** なんだか最近寝ても疲れが取れないんだよねー。

   Furigana (nguồn): 寝＝ね、疲＝つか、取＝と

   **B:** あ、本当？　肩揉んであげようか。

   Furigana (nguồn): 本当＝ほんとう、肩＝かた、揉＝も

   **A:** 本当？　いいの？

5.

   **A:** お見舞いに行く時、何を持って行きましょうか？

   Furigana (nguồn): 時＝とき、何＝なに、持＝も

   **B:** そうですね、普通だけど、花にしようか？

   Furigana (nguồn): 普通＝ふつう、花＝はな

   **A:** ええ、切り花⁵でしたよね。

   Furigana (nguồn): 切＝き、花＝ばな

   Ghi chú ký hiệu (biên tập): Số 5 kèm biểu tượng bóng đèn sau “切り花”.

6. C

   **A:** ねー、こんどまたディズニーランドに行こうよ。

   **B:** え～。また～。そのうちね。

   **A:** そのうちっていつ？

7.

   **A:** どこの病院に入院したんですか？

   Furigana (nguồn): 病院＝びょういん

   **B:** 西新宿の大学病院みたいですよ。

   Furigana (nguồn): 西新宿＝にししんじゅく、大学＝だいがく

   **A:** あ、そうですか。
