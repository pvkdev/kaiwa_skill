## Unit 4 — section 1

CD 29

1. C

   **A:** 新しく始まるドラマ、おもしろそうだよ。

   Furigana (nguồn): 新＝あたら、始＝はじ

   **B:** あー、あんまり興味ないな。

   Furigana (nguồn): 興味＝きょうみ

2. C

   **A:** 木村さんってどんな人？

   Furigana (nguồn): 木村＝きむら、人＝ひと

   **B:** うん、明るくて社交的な人だよ。

   Furigana (nguồn): 明＝あか、社交的＝しゃこうてき、人＝ひと

3. C

   **A:** あー、今日は雨が降りそうだね。

   Furigana (nguồn): 今日＝きょう、雨＝あめ、降＝ふ

   **B:** うん、かさを持って行った方が良さそうだね。

   Furigana (nguồn): 持＝も、行＝い、方＝ほう、良＝よ

4.

   **A:** すみませーん。宿題を忘れてしまいました～。

   Furigana (nguồn): 宿題＝しゅくだい、忘＝わす

   **B:** そうですか！

5. C

   **A:** あんなこと言うつもりじゃなかったのに…。

   Furigana (nguồn): 言＝い

   **B:** 口は災いの元¹だね。

   Furigana (nguồn): 口＝くち、災＝わざわ、元＝もと

   Ghi chú ký hiệu (biên tập): Số 1 kèm biểu tượng bóng đèn sau “元”.

6.

   **B:** そうだね、日本では家に入る時、くつを脱ぐんですよ。

   Furigana (nguồn): 日本＝にほん、家＝いえ、入＝はい、時＝とき、脱＝ぬ

7. C

   Furigana (nguồn): 私＝わたし、料理＝りょうり、好＝す

   Furigana (nguồn): 一度＝いちど、食＝た

8. C

   **B:** やっぱ²、宝くじかな。

   Furigana (nguồn): 宝＝たから

   Ghi chú ký hiệu (biên tập): Số 2 kèm biểu tượng bóng đèn sau “やっぱ”.
