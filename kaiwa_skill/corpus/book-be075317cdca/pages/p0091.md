## Unit 4 — section 3

CD 31

1. C

   **A:** 明子、拓也くんといい感じじゃない？

   Furigana (nguồn): 明子＝あきこ、拓也＝たくや、感＝かん

   **B:** うん、でも友だち以上、恋人未満かな。

   Furigana (nguồn): 友＝とも、以上＝いじょう、恋人＝こいびと、未満＝みまん

2. C

   **A:** このセーターどうかな？　この色いいよね？

   Furigana (nguồn): 色＝いろ

   **B:** うん、その色似合うね。

   Furigana (nguồn): 似＝に、合＝あ

3. C

   **A:** あ～あ、目が疲れた。

   Furigana (nguồn): 目＝め、疲＝つか

   **B:** 遠くを見たほうがいいよ。緑を見たり…。

   Furigana (nguồn): 遠＝とお、見＝み、緑＝みどり

4. C

   **A:** なんだか、北村さん、最近怒りっぽくない？

   Furigana (nguồn): 北村＝きたむら、最近＝さいきん、怒＝おこ

   **B:** うん、ストレスたまってんだ⁶よ。

   Ghi chú ký hiệu (biên tập): Số 6 kèm biểu tượng bóng đèn sau “たまってんだ”.

5. C

   **A:** あー、よく食べた。もう食べれない。

   Furigana (nguồn): 食＝た

   **B:** 本当！　これで寝ちゃえたらいいのに。

   Furigana (nguồn): 本当＝ほんとう、寝＝ね

6.

   **A:** あのー、10分くらい前にカレー注文したんですけど…。

   Furigana (nguồn): 10分＝じゅっぷん、前＝まえ、注文＝ちゅうもん

   **B:** あ、申し訳ありません。ただ今、見てまいります。

   Furigana (nguồn): 申＝もう、訳＝わけ、今＝いま

7.

   **A:** あのー、このカレー、髪の毛が入ってるんですけど…。

   Furigana (nguồn): 髪＝かみ、毛＝け、入＝はい

   **B:** あ、すみません。新しいものとお取替えします。

   Furigana (nguồn): 新＝あたら、取＝とり、替＝か

8.

   **A:** あのー、昨日、こちらでこのかさ買ったんですけど、すぐにこわれちゃったんですが…。

   Furigana (nguồn): 昨日＝きのう、買＝か

   **B:** あ、すみません。では、新しいものと交換いたします。

   Furigana (nguồn): 交換＝こうかん

9.

   **A:** あのー、返品はできませんか？

   Furigana (nguồn): 返品＝へんぴん

   **B:** あ、では、少々お待ちください。店長を呼んできます。

   Furigana (nguồn): 少々＝しょうしょう、待＝ま、店長＝てんちょう、呼＝よ

10.

    **A:** お客様、では、お代をお返しいたします。

    Furigana (nguồn): 客様＝きゃくさま、代＝だい、返＝かえ

    **B:** あ、おねがいします。
