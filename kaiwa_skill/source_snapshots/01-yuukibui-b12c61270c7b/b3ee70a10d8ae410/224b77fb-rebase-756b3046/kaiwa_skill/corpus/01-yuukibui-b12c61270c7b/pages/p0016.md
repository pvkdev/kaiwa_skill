## 《語句の使い方》

Furigana (nguồn): 語＝ご；句＝く；使＝つか；方＝かた

〔本文会話〕

Furigana (nguồn): 本文会話＝ほんぶんかいわ

<a id="p0016-b002"></a>

1. ＿＿＿＿**は**＿＿＿＿**のように** (p.2 l.6)

(1) プラモーという名前**は、**日本の鈴木**のように**ありふれた名前です。

Furigana (nguồn): 名前＝なまえ；日本＝にほん；鈴木＝すずき；名前＝なまえ

(2) 私**は**スミスさん**のように**日本語が上手になりたいです。

Furigana (nguồn): 私＝わたし；日本語＝にほんご；上手＝じょうず

<a id="p0016-b003"></a>

2. ＿＿＿＿**は**＿＿＿＿**として知られている** (p.2 l.6)

Furigana (nguồn): 知＝し

(1) チェンマイ**は**避暑地**として知られています**。

Furigana (nguồn): 避暑地＝ひしょち；知＝し

(2) パンダ**は**めずらしい動物**として知られています**。

Furigana (nguồn): 動物＝どうぶつ；知＝し

<a id="p0016-b004"></a>

3. ＿＿＿＿**ことになった** (p.2 l.9)

(1) このたび、本社で研修を受ける**ことになりました**。

Furigana (nguồn): 本社＝ほんしゃ；研修＝けんしゅう；受＝う

(2) 彼は来月、結婚する**ことになりました**。

Furigana (nguồn): 彼＝かれ；来月＝らいげつ；結婚＝けっこん

<a id="p0016-b005"></a>

4. ＿＿＿＿**が、まだ十分ではない** (p.2 l.9)

Furigana (nguồn): 十分＝じゅうぶん

(1) 日本語は大学時代に勉強しました**が、まだ十分ではありません**。

Furigana (nguồn): 日本語＝にほんご；大学時代＝だいがくじだい；勉強＝べんきょう；十分＝じゅうぶん

(2) 給料は二十五万円もらっています**が、まだ十分ではありません**。

Furigana (nguồn): 給料＝きゅうりょう；二十五万円＝にじゅうごまんえん；十分＝じゅうぶん

<a id="p0016-b006"></a>

5. ＿＿＿＿**ためには、**＿＿＿＿**ことが必要だと思う** (p.2 l.10)

Furigana (nguồn): 必要＝ひつよう；思＝おも

(1) 日本語が上手になる**ためには、**たくさん話す**ことが必要だと思います**。

Furigana (nguồn): 日本語＝にほんご；上手＝じょうず；話＝はな；必要＝ひつよう；思＝おも

(2) 日本の会社で働く**ためには、**日本語が上手に話せる**ことが必要だと思います**。

Furigana (nguồn): 日本＝にほん；会社＝かいしゃ；働＝はたら；日本語＝にほんご；上手＝じょうず；話＝はな；必要＝ひつよう；思＝おも

<a id="p0016-b007"></a>

6. ＿＿＿＿**たばかり** (p.2 l.12)

(1) 先週、日本へ来**たばかり**だから、何もわかりません。

Furigana (nguồn): 先週＝せんしゅう；日本＝にほん；来＝き；何＝なに

(2) この機械は、きのうなおし**たばかり**なのに、またこわれてしまいました。

Furigana (nguồn): 機械＝きかい
