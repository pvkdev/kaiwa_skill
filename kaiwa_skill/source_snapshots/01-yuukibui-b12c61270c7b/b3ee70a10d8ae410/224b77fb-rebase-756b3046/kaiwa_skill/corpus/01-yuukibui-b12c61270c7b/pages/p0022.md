## 《語句の使い方》

Furigana (nguồn): 語＝ご；句＝く；使＝つか；方＝かた

〔本文会話〕

Furigana (nguồn): 本文会話＝ほんぶんかいわ

1. ＿＿＿＿**というのは**＿＿＿＿**という意味です**。(p.6 l.10)

Furigana (nguồn): 意味＝いみ

(1) 「そうおん」**というのは、**うるさい音**という意味です**。

Furigana (nguồn): 音＝おと；意味＝いみ

(2) 「通勤」**というのは、**勤めている所に通う**という意味です**。

Furigana (nguồn): 通勤＝つうきん；勤＝つと；所＝ところ；通＝かよ；意味＝いみ

<a id="p0022-b002"></a>

2. ＿＿＿＿**というのは**＿＿＿＿**とか**＿＿＿＿**なんかのことです**。(p.6 l.11)

(1) 「そうおん」**というのは、**となりのテレビの音**とか、**自動車の音**なんかのことです**。

Furigana (nguồn): 音＝おと；自動車＝じどうしゃ；音＝おと

(2) 交通機関**というのは、**電車**とか、**バス**なんかのことです**。

Furigana (nguồn): 交通機関＝こうつうきかん；電車＝でんしゃ

<a id="p0022-b003"></a>

〔類話〕

Furigana (nguồn): 類話＝るいわ

3. ＿＿＿＿**は**＿＿＿＿**なら**＿＿＿＿**に当たる** (p.6 l.20)

Furigana (nguồn): 当＝あ

(1) 頭取**は、**会社**なら**社長**に当たります**。

Furigana (nguồn): 頭取＝とうどり；会社＝かいしゃ；社長＝しゃちょう；当＝あ

(2) 犬の一年**は、**人間**なら**六、七年**に当たります**。

Furigana (nguồn): 犬＝いぬ；一年＝いちねん；人間＝にんげん；六＝ろく；七年＝しちねん；当＝あ

<a id="p0022-b004"></a>

4. ＿＿＿＿**ぐらいしか**＿＿＿＿**ない** (p.7 l.7)

(1) 私の辞書には「雨がふる」「手をふる」**ぐらいしか**出てい**ないんです**。

Furigana (nguồn): 私＝わたし；辞書＝じしょ；雨＝あめ；手＝て；出＝で

(2) 料理は目玉焼き**ぐらいしか**作れ**ません**。

Furigana (nguồn): 料理＝りょうり；目玉焼＝めだまや；作＝つく

<a id="p0022-b005"></a>

5. **一般的に** (p.7 l.16)

Furigana (nguồn): 一般的＝いっぱんてき

(1) 日本語では、**一般的に**、「スマート」という言葉を頭がいいという意味では使いません。

Furigana (nguồn): 日本語＝にほんご；一般的＝いっぱんてき；言葉＝ことば；頭＝あたま；意味＝いみ；使＝つか

(2) 日本の会社では、人を呼ぶ時、**一般的に**役職名、またはみょう字で呼びます。

Furigana (nguồn): 日本＝にほん；会社＝かいしゃ；人＝ひと；呼＝よ；時＝とき；一般的＝いっぱんてき；役職名＝やくしょくめい；字＝じ；呼＝よ
