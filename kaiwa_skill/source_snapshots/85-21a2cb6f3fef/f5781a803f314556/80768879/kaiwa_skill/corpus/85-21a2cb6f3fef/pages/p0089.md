## よく使う丁寧表現　Frequently Used Polite Expressions

Furigana (nguồn): 使＝つか、丁寧表現＝ていねいひょうげん。

| Dạng thường | Dạng lịch sự |
|---|---|
| 今（いま） | ただ今（いま） |
| さっき | 先ほど（さき） |
| 後で（あと） | 後ほど（のち） |
| もうすぐ | 間もなく（ま） |

| Dạng thường | Dạng lịch sự |
|---|---|
| すぐに | 直ちに（ただ）／さっそく |
| 前に（まえ） | 以前に（いぜん） |
| この間（あいだ） | 先日（せんじつ） |

| Dạng thường | Dạng lịch sự |
|---|---|
| その日（ひ） | 当日（とうじつ） |
| 今回（こんかい） | この度（たび） |
| ちょっと／少し（すこ） | 少々（しょうしょう） |

| Dạng thường | Dạng lịch sự |
|---|---|
| ～くらい | ～ほど |
| 家（いえ） | お住まい（す） |
| 皆さん（みな） | 皆様（みなさま） |
| 私たち（わたし） | 私ども（わたくし） |

Ghi chú bố cục (biên tập): nguồn in bốn bảng nhỏ đặt cạnh nhau; bảng 2 ô “すぐに” đối ứng cả「直ちに」「さっそく」theo hai dòng trong một ô, bảng 3 ô「少々」đối ứng cả「ちょっと」「少し」qua ô dọc. Các ngoặc chứa furigana trong Markdown là ký hiệu biên tập, không phải dấu ngoặc in trong bảng. Footer in số 176 và 177.
