# 5「そこをなんとか」―依頼・指示―

Furigana (nguồn): 依頼＝いらい、指示＝しじ

最近、どんなことを頼まれましたか。

Furigana (nguồn): 頼＝たの

断りたかったのに断れなかったことはありませんでしたか。

Furigana (nguồn): 断（「断りたかった」）＝ことわ

<a id="p0049-b002"></a>
## こんなとき、どう言いますか。

次のような場面では、どのように言いますか。適切なものを選んでください。

Furigana (nguồn): 場面＝ばめん、適切＝てきせつ、選＝えら

① 小山さん　35才　会社員

Furigana (nguồn): 小山＝こやま、会社員＝かいしゃいん

|  | 場面 (biên tập) |
|---|---|
| ア | 会社で忙しそうな同僚に… |
| イ | 家で妻に… |
| ウ | 友達の家で奥さんに… |
| エ | 喫茶店で店員に… |

Furigana (nguồn): 忙＝いそが、同僚＝どうりょう、妻＝つま、友達＝ともだち、奥＝おく、喫茶店＝きっさてん、店員＝てんいん

Lựa chọn ① (biên tập):

a. じゃ、コーヒーで。

b. コーヒーかなんかいただけるとありがたいんですが。

c. コーヒー入れて。

d. 手が空いていたら、コーヒー入れてくれないかな。

Furigana (nguồn): 空＝あ

<a id="p0049-b003"></a>
② 増田さん　33才　教師

Furigana (nguồn): 増田＝ますだ、教師＝きょうし

|  | 場面 (biên tập) |
|---|---|
| ア | 学校の会議で司会者として… |
| イ | デパートで買い物をしている友達に… |
| ウ | 家で水道工事の人に… |
| エ | 学校で学生に… |

Furigana (nguồn): 会議＝かいぎ、司会者＝しかいしゃ、友達＝ともだち、水道工事＝すいどうこうじ

Lựa chọn ② (biên tập):

a. ３時までに終わること。

Furigana (nguồn): 終＝お

b. ３時までに、終わらせたいんですが。

c. ３時までに終われる？　ちょっと、用事があるから、そうしてくれたらうれしいなあ。

Furigana (nguồn): 用事＝ようじ

d. ちょっと、用事があるんで、３時までに終わっていただけますか。
