# Bài giảng ngữ pháp Harumii

Mỗi file `.md` là một mẫu ngữ pháp. Đọc kỹ `HUONG-DAN-AI.md` (hợp đồng dữ liệu) trước khi biên soạn:
giữ nguyên `id`, đúng cấu trúc markdown, thêm mẫu mới bằng `id: new`. Biên soạn xong nén lại thành zip và
upload ở trang admin "Biên soạn với AI" — dữ liệu được lưu thành bản New, chỉ thay bài đang dùng khi admin áp dụng.
