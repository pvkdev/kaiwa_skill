# Danh sách từ vựng Minna N5–N4

Đặt danh sách của từng bài ở đây. Ví dụ, `lesson-39.md` chứa từ của bài 39. Có thể giữ file CSV, bảng tính hoặc tài liệu gộp sẵn có. Với tài liệu gộp, ghi số bài ở một cột hoặc dùng tiêu đề như `## Bài 39` để AI tìm đúng danh sách.

Mỗi mục có thể ghi từ tiếng Nhật, cách đọc và nghĩa tiếng Việt. Giữ nhóm từ hoặc thứ tự dạy nếu tài liệu đã có. Nếu chỉ có danh sách theo cấp độ, dùng tên như `n4.md`; AI có thể tra độ khó trong file này trong lúc chờ danh sách theo bài.
