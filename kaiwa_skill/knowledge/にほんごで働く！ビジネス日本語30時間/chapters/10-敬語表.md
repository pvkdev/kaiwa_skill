## 特別な形の敬語 — Các dạng kính ngữ đặc biệt (trang in 133; PDF 141)

Bảng phân biệt lời tôn kính khi nói về đối phương (尊敬語、～さんはV), lời khiêm nhường cho hành động của mình có liên quan đến đối phương (謙譲語) và lời lịch sự trang trọng khi nói về hành động của mình (丁重語). Ô trống giữ nguyên như nguồn.

| Động từ thường | 尊敬語 — đối phương | 謙譲語 — hành động của mình liên quan đối phương | 丁重語 — hành động của mình |
|---|---|---|---|
| いる — ở, có mặt | いらっしゃいます／おいでになります — có mặt |  | おります — có mặt |
| 行く — đi | いらっしゃいます／おいでになります — đi |  | 参ります — đi |
| 来る — đến | いらっしゃいます／おいでになります／おこしになります／見えます — đến |  | 参ります — đến |
| 訪問する — đến thăm |  | 伺います／おじゃまします — đến thăm |  |
| 質問する — hỏi |  | 伺います — hỏi |  |
| 聞く — nghe, hỏi |  | 伺います — hỏi, nghe |  |
| する — làm | なさいます — làm |  | いたします — làm |
| 食べる／飲む — ăn/uống | 召し上がります — ăn/uống |  | いただきます — ăn/uống |
| 見る — xem | ご覧になります — xem | 拝見します — xem |  |
| 会う — gặp |  | お目にかかります — gặp |  |
| あげる — cho, tặng |  | さしあげます — cho, tặng |  |
| もらう — nhận |  | いただきます — nhận |  |
| くれる — cho mình | くださいます — cho mình |  |  |

## 敬語の形 — Các mẫu tạo kính ngữ (trang in 134; PDF 142)

| Loại | Dạng | Ví dụ in trong sách và nghĩa Việt |
|---|---|---|
| 尊敬語 — tôn kính | ～れる／～られる | 読まれます — đọc; 出られます — ra ngoài |
| 尊敬語 — tôn kính | お～になる／ご～になる | お出かけになります — đi ra ngoài; ご見学になります — tham quan |
| 謙譲語 — khiêm nhường | お～する／ご～する | お持ちします — tôi mang; ご紹介します — tôi giới thiệu |
| 謙譲語 — khiêm nhường | お～いたす／ご～いたす | お持ちいたします — tôi xin mang; ご紹介いたします — tôi xin giới thiệu |
| 謙譲語 — khiêm nhường | ～（さ）せていただきます | 失礼させていただきます — tôi xin phép cáo lui |
